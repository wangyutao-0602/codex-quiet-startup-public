# 静态人物版验证记录

版本：1.2.0。日期：2026-10-23。平台：macOS 26.5.1、Apple Silicon arm64。

## 已执行的验证

- `npm test`：6 项核心与协议测试通过。
- `npm run test:render`：真实 PNG 解码、500 条轮廓、五阶段离屏 Canvas 渲染通过。6.18、7.3、7.6、7.85、8.5 秒使用同一人物图片和相同绘制位置，无肘腕动作状态。原生播放阶段保持不透明，完成后停止 rAF。
- Microsoft Edge：Retina 2×、14 项浏览器检查通过，包括设置、跳过、自然结束、减少动态效果、图片失败回退和模拟宿主移除。已查看完整场景截图。
- macOS 本机构建、用户目录安装、签名校验通过。已安装版本原生烟测输出 `SMOKE PASS`、`motionEngine=static`、`paths=500`、`imageWidth=1211`，9 秒完成且 `playing=false`。
- 原生 6.8–8.98 秒短时采样：帧间隔 15–18 ms，主要为 16–17 ms。这是本机样本，不是所有设备的性能保证。

以上为静态版实现完成时执行的测试，公开文档整理没有改变运行代码。本仓库不发布本机日志和构建缓存。复验命令见 [测试步骤](TEST-RESULTS.md)。
