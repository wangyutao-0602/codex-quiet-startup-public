# 静态角色素材

当前文件：`assets/character.png`，1211 × 1299 像素，RGBA 透明 PNG。由内置图像生成工具生成和局部编辑。

人物为短茶色头发、清冷神情的二次元研究员，白大褂搭配深色内搭。固定抬手姿势，掌心朝向观众；食指和中指伸展，无名指与小指自然弯曲，拇指向侧面展开。保持手腕与前臂连接自然，人物背景透明。

最终编辑要求：保留脸、发型、服装、身体姿势和抬手位置，依据选定的手部参考修正手指形态。运行时使用一张完整立绘，不拆分人物关节，不进行人物形变。

更换素材时，推荐使用有透明背景的 PNG。可从设置面板导入，或替换默认文件后重新构建。人物轮廓从实际图片自动提取，与图片使用同一坐标变换。

本说明是素材制作要求的概述，不是可精确复现生成结果的随机种子或完整生成记录。素材权利说明见仓库 README。
